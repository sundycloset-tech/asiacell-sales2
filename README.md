# نظام مبيعات آسياسيل إكسبريس | بني منصور

تطبيق بسيط لتسجيل المبيعات يعمل بدون إنترنت، وبدون تسجيل دخول أو قاعدة بيانات.

## التشغيل
- افتح رابط التطبيق في Chrome على أندرويد.
- ثبّته: اضغط ⋮ ثم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- بعد أول فتح بالإنترنت يعمل بدونه.

## الاستخدام
- اضغط أي خانة واكتب، ويُحفظ كل شيء تلقائياً.
- **+ صف** يضيف صفاً. **حذف الصف**: اضغط خانة في الصف ثم الزر.
- **السابق / التالي** للتنقل بين الأشهر، و**+ شهر** يفتح الشهر التالي. الأشهر القديمة تبقى محفوظة.
- **مجموع المبيعات** = مجموع (السعر × العدد) لكل صف. إذا تُرك العدد فارغاً يُحسب 1.

## النسخ الاحتياطي
- **نسخ احتياطي**: يحفظ ملف JSON أو يفتح قائمة المشاركة (أرسله لنفسك على واتساب مثلاً).
- **استعادة**: اختر ذلك الملف على الهاتف نفسه أو هاتف آخر. تُستبدل كل البيانات الحالية.
- خذ نسخة احتياطية بشكل دوري، لأن البيانات مخزّنة في متصفح الهاتف نفسه.
